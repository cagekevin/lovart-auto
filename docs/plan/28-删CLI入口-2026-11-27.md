# 删 CLI 入口：只留 GUI + 本机 HTTP · 施工契约

> 状态：**待裁定**（2026-11-27）——见 §1.1，有一处必须先由你拍板
> 用户原话：「我准备删掉 cli 模块，因为我们现在已经通过 curl 和 gui 已经满足需求了，
> cli 目前是多余的，你先做好 plan，删的同时注意修剪形状，该重构的地方重构，让代码更整洁」
> 判据：ADR-0001（一处样本）· ADR-0005（一个能力一个入口）· ADR-0008（数据链不清不许动手）

---

## 1. 第一性问题与一处必须先裁定的事

### 1.1 先裁定：AI 四步怎么办

`README.md:11-18` 的「AI 只做四步」**四步里三步是 CLI**：

| 步 | 现命令 | 删 CLI 后 |
|---|---|---|
| 1 写提示词 | 落到 `data/inbox/x.jsonl` | 不变（写文件） |
| 2 **先检查** | `lovart-client --check --prompts …` | **没了** |
| 3 生成 | `lovart-client --prompts …` | 没了（可改 `POST /tasks`） |
| 4 查进度 | `lovart-client --status --json` | 没了（可改 `GET /state`） |

三选一，**必须你定**：

- **A. 真删 CLI，AI 四步改写为 HTTP**（`curl -X POST …/tasks`、`GET …/state`）。
  代价：AI 要先读 `data/var/http-token`；`--check` 没有等价端点（见 §3.2）；
- **B. 删 `run.rs` 的跑批，保留 `--check` / `--status` / `--list-models` 这类只读命令**
  （它们不联网、不起批次，是 AI 自检的入口）；
- **C. 全删，README 只写给「人」看**，AI 那四步整节删掉（承认 AI 走 HTTP 或 GUI）。

> 我的建议是 **B**：只读命令没有第二个入口能替代（`--check` 校验字段/别名/ratio/size
> 在 HTTP 侧**根本不存在**），而「跑批」确实与 `/tasks` 重复。
> 但这是产品决定，按写plan方法 §7-3 必须你点头；你没点头前 §2 之后按 **A** 写（最激进）。

### 1.2 第一性问题

> **删掉 CLI 之后，同一能力是否只剩一个入口？**

CLI 与 GUI/HTTP 重复的能力（跑批、看状态、列模型）⇒ 删 CLI 是对的（ADR-0005）。
CLI **独有**的能力（`--check` 离线校验、`--status-table`）⇒ 删掉就是**删能力**，不是去重。

## 3. 重构（「修剪形状」具体修什么）

### 3.1 `run.rs` 里有没有该下沉到 core 的东西

必须先查：`run.rs` 的 `resolve_refs`（`:717`）与 `service::refs::resolve_refs_core` 是否重复。
- 若 `run.rs` 那版只是薄封装 ⇒ 直接删，不留第二份；
- 若它有自己的逻辑（如 CLI 独有的路径解析）⇒ 先确认 GUI 侧不需要，再删。

同理 `report` / `counter` 相关：`run.rs` 里若只是调 `engine::report`，删了不留空洞。

### 3.2 `--check` 的能力去哪（选 A 时的必答题）

`--check` 做的是「读文件 → `parse_prompts` 校验 → 按行号报错」，且**不联网**。
GUI 的 `validate_draft` 只收**一段文本**，不收文件。所以选 A 就等于**失去**
「AI 写完文件后自检」这条能力——README 的 AI 工作流会断。

若选 A 且要保住它，唯一正解是给 HTTP 加一个 `POST /check`（收 JSONL 文本，回错误列表），
那是**新增能力**，属另一条 plan，不混进「删 CLI」。

### 3.3 文档形状收口

删完之后 `README.md` 应该只剩两条入口：
1. 人：双击 exe → GUI；
2. 其他程序：本机 HTTP（`docs/接入指南-本机HTTP-…`）。

`AGENTS.md` 的「命令」表里凡 `lovart-client --xxx` 的行必须删或改成 GUI/HTTP 对应物。

## 5. 不做

- 不为「以后可能要命令行」保留半套 `cli.rs`（ADR-0001：半收口比不做更糟）；
- 不在本轮新增 `POST /check`（若需要，另开 plan）；
- 不改 `crates/lovart-core`（CLI 只在 `src-tauri` 适配层）；
- 不动 `fixtures/` 与 `tests/` 里与 CLI 无关的用例。

## 9. 怎么撤

- 代码：`git revert <commit>`（删文件用 revert 最干净，`checkout` 找不回已删文件）；
- 文档：同一 commit 回退；
- 无数据副作用（CLI 只读/写同一套 `data/`，不产生独有数据）。
