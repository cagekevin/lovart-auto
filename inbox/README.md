## 1. 边界：AI 做什么、不做什么

### 1.1 AI 做

- 写 `.jsonl`（格式见 §2）；
- 跑 `--check` 自检，按行号改错，直到全绿。

### 1.2 AI 不做

- **不提交任务**、不跑图、不扣积分；
- **不覆盖**用户正在编辑的 `prompts.jsonl`；
- **不改**已有行（用户已检查过的内容）。

### 1.3 追加规则（2026-10-24 起）

用户说「继续 / 再来 N 条」时：

- **往该系列已有的 `inbox/*.jsonl` 末尾追加**；
- 不新建文件、不覆盖、不改已有行；
- 垫图与 `ratio` / `size` **沿用该文件既有值**；
- 只有用户明确说「另开文件 / 新系列」时才新建。

> 为什么单独一个目录：AI 直接覆盖 `prompts.jsonl` 会毁掉用户正在编辑的内容，所以给 AI 一个独立落点，不碰编辑区。

## 2. 文件格式

### 2.1 契约

`*.jsonl`，**一行一条 JSON 对象**，格式与 `prompts.jsonl` 完全相同。

📖 **字段穷举 / 合法值 / 自检流程见 [`../README.md`](../README.md) 的「prompts.jsonl 格式」一节**——本文不抄第二份（抄了必分叉）。

一句话记：只允许 `prompt` / `ratio` / `size` / `refs`，**未知字段直接报错**。

### 2.2 命名

`<日期>-<主题>-<条数>.jsonl`，例 `2026-10-24-HKH真实生活静物-20.jsonl`。

### 2.3 HKH 批次固定参数

| `ratio` | `3:4` |
| `size` | `2K` |
| `model` | 不写，走兜底 `nano-bn-2` |
| `refs` | `["G:/品牌更新.library/images/MOWKQCN0BAES0.info/023.jpg"]` |

## 3. 用法：三步命令

```bash
# ① 自检（不联网、不提交、不扣积分；有错按行号报）
lovart-client --check   --prompts inbox/2026-10-24-HKH真实生活静物-20.jsonl

# ② 看计划（每条的行号 / 模型 / 比例 / 尺寸）
lovart-client --dry-run --prompts inbox/2026-10-24-HKH真实生活静物-20.jsonl

# ③ 真跑（用户执行，AI 不做）
lovart-client           --prompts inbox/2026-10-24-HKH真实生活静物-20.jsonl
```

`lovart-client` = `src-tauri/target/release/lovart-client`；**双击它开界面**。

### 3.1 导入后归位

GUI 的「从 inbox 导入」会把文件**移进 `inbox/imported/`**——同一文件不会导两次（重名加时间戳，不覆盖）。要再导一遍去 `imported/` 里拿。

## 4. 提示词公式（核心）

### 4.1 公式

```text
真实生活美学静物摄影，在【场景环境】的环境里，【产品怎么放】，【道具 2~4 件】，【光从哪来、落在什么上】，站在两步外拍，产品落在画面偏右三分之一处，【相机】拍摄的生活记录感，画面保持简洁、内容只有产品与这几件道具，整体松弛、真实、有 INS 生活美学感，罐身比例与参考图一致、标签清晰可辨。无男性、无人物面部与全身；不出现餐食与用餐场景；产品不落地。
```

**以后一律按这个填空，不另创句式。**

### 4.2 五个空怎么填

| 空 | 填什么 | 例子 |
| --- | --- | --- |
| 【场景环境】 | 真实地点 + 具体位置 | 清晨浴室洗手台 / 浴室镜前 / 浴缸边 / 淋浴后壁龛 / 夜里卧室床头柜 / 卧室梳妆台 / 午后飘窗 / 床单上 / 酒店洗手台 / 傍晚客厅沙发 / 泳池边躺椅 / 游轮梳妆台 / 车内副驾 / 黄昏阳台 |
| 【产品怎么放】 | `图1的HKH胶囊精华` + 动作 + 承托物 | 斜靠在托盘边 / 侧卧在巾面褶里 / 立在台灯座旁 / 放在沙滩巾上 / 半露在包侧袋外 |
| 【道具 2~4 件】 | 同一空间、女性日常物 | 发圈、折叠毛巾、木梳、首饰盘、干花、香薰、杂志、草帽、墨镜、贝壳、缎带、素陶碟、亚麻织物、气泡水 / 咖啡 |
| 【光】 | 什么光 + 落在哪 | 侧窗晨光落在台面与墙面 / 台灯暖光只照亮柜面一角 / 正午阳光把池水照得发亮 / 晚光染暖藤椅 |
| 【相机】 | 设备 + 拍法，**按 §7 选** | iPhone 随手拍 / 富士 X100V / 35mm 胶片机配 Portra 400 |

### 4.3 三条固定句（不拆不改）

| 句子 | 管什么 |
| --- | --- |
| `站在两步外拍，产品落在画面偏右三分之一处` | 距离与位置，防九宫格正中、防大头照 |
| `画面保持简洁、内容只有产品与这几件道具` | 道具克制，防模型自己撒东西 |
| `无男性、无人物面部与全身；不出现餐食与用餐场景；产品不落地。` | 唯一收尾排除项 |

### 4.4 正面写，别写负面

除收尾那一句，**别处不加「不 / 无」开头的短句**。

| ❌ | ✅ |
| --- | --- |
| 产品落在偏右处，不在正中 | 产品落在画面偏右三分之一处 |
| 不额外添东西 | 画面保持简洁、内容只有产品与这几件道具 |
| 别贴近拍 | 站在两步外拍，台面和周围环境都进画面 |

### 4.5 完整示例

> 真实生活美学静物摄影，在泳池边午后躺椅的环境里，图1的HKH胶囊精华放在摊开的白色沙滩巾上，旁边草帽、墨镜和一杯冰气泡水，正午阳光把池水照得发亮，站在两步外拍，产品落在画面偏右三分之一处，iPhone 拍摄的生活记录感，画面保持简洁、内容只有产品与这几件道具，整体松弛、真实、有 INS 生活美学感，罐身比例与参考图一致、标签清晰可辨。无男性、无人物面部与全身；不出现餐食与用餐场景；产品不落地。

## 5. 硬规则（违反 = 废品）

> 总原则：**审美放开，逻辑收紧**。风格气质、构图巧思、光影氛围写方向就够，别逐条枚举；但场景成不成立、使用叙事通不通、产品与道具的关系对不对，一条都不能错。

### 5.1 产品外观只靠参考图

- 不写颜色、材质、瓶盖、标签样式、内装物；
- 只用锚定句：`图1的HKH胶囊精华……，罐身比例与参考图一致、标签清晰可辨`；
- **禁止描述内容物**：不写颗粒、不写散落、不写托举内容物。
  **原因**：单生成的胶囊颗粒 99% 与实物不符，写进提示词必翻车。

### 5.2 场景必须过逻辑一问

每个场景要能回答：**「女生会在这里用它吗」**。

| 可以 | 写法 |
| --- | --- |
| 浴室 | 洗手台 / 镜前 / 浴缸边 / 淋浴后壁龛 |
| 卧室 | 床头柜 / 梳妆台 / 飘窗 / 床单上 |
| 差旅 | 酒店洗手台 / 酒店床头 |
| 客厅 | 沙发（面膜时光）/ 边几 |
| 影棚 | 石灰岩台面 / 平铺 / 窗光角落 |
| 度假（点缀） | 沙滩巾或草编垫、泳池池沿、帆船甲板、游轮梳妆台、海边咖啡馆吧台 |

**一律禁止**（历史翻车实证）：厨房备餐区、餐桌、玄关、叠衣台、衣帽间换季、冰箱、水面木台、纯背景板式的小木船。

### 5.3 餐食 vs 饮品（2026-10-24 修正）

- **禁餐食**：早餐桌、厨房备餐、餐盘餐具、切开的椰子等水果、甜点零食；
- **饮品允许**：咖啡、气泡水、冷萃、茶——它们是生活气息的道具，不算食物。

> 这条的由来：早先批次把产品放到了餐桌上，出图变成「护肤品端上饭桌」。要防的是**餐桌语境**，不是杯子。

### 5.4 人物

- **不出现整个的人和脸，也不出现男性**（男性一律不合格）；
- 人物非必需；一旦出现只允许局部：手 / 手臂 / 肩 / 腿。

### 5.5 摆放

- **产品不落地**：只能放椅子 / 沙发 / 桌子 / 台面 / 托盘 / 腿上；
- 地板、地毯、草地、马路、沙面一律不允许。

### 5.6 禁止任何炫技

只为画面效果服务的戏一律不加：悬浮、爆裂、液体飞溅、3×3 网格、海报式排版、风格锁、单色情绪片、符号化意象、水雾光柱、浮动尘埃、超现实融合。

只写**真实生活动线 + 常规产品摄影手法**（平铺、静物、正常场景带产品）。

## 6. 写法禁用项

| # | 禁止 | 说明 |
| --- | --- | --- |
| 1 | **特写** | 不写微距、大特写、近距离特写、产品特写、细节特写。镜头一贴近，场景叙事就没了，出来的是产品大头照。 |
| 2 | **占比** | 不写「占画面高度约四分之一」这类量化描述。 |
| 3 | **摄影术语与参数** | `机位` / `景别` / `中景` / `50mm` / `f/2.8` / `焦点` / `虚化` / `镜头对台面下压15度` / `与飘窗面成30度` 一律不写。视角最多写「俯拍 / 平视 / 从侧面 / 低一点的角度」。 |
| 4 | **`背景是模糊的×××`** | 环境用「在……的环境里」写（见 §4.1）。 |
| 5 | **文字限制句** | 不写「画面不出现任何文字、广告语、排版、水印」这类句子。 |
| 6 | **额外负面句** | 除收尾那一句，不再加「不 / 无」开头的短句（见 §4.4）。 |

**判据**：一条提示词读下来要像人在描述一个真实场景，不能像参数表；**自己读不通的句子就是错的**。

## 7. 相机准入

**只允许 INS 静物 / 生活记录这一路的设备**：

- `iPhone 随手拍`、手机生活记录感
- 富士 X100V / X-T4（胶片模拟）
- 理光 GR III（街拍生活感）
- 35mm 胶片机 + Kodak Portra 400
- 索尼 A7 / 徕卡 M 配 50mm 定焦

**禁止**（一写就出商业大片或怪画面）：

- 运动相机（GoPro）、无人机、安防 / 监控摄像头
- 长焦（70mm 以上、200mm 大炮）、微距镜头
- 鱼眼、超广角、移轴
- 电影机、专业影棚中画幅硬光布光

**判据**：读完能想象成「一个女生在生活里拿手上的设备随手拍了一张」，就合格。

## 8. 风格与美学

### 8.1 方向

1. 优先：日常生活、慵懒、贵妇 / 老钱风 / 网红风 / ins 风；其他风格不禁止，只是不优先。
2. 主目标：**慵懒的精致抓拍感**——姿态松弛、构图随意，但画面完成度不降。
3. 色调**以方向图为准**；有方向图时不要套默认奶油色。

### 8.2 道具

- 只用女性相关：护肤品、化妆品、首饰、干花、书、茶杯、咖啡、亚麻织物、草帽、贝壳……
- 男性相关一律不出现（如男士手表这类深色系）。

### 8.3 老钱风怎么落地

不要高饱和、天然材质、安静克制、**旧而不破**（禁止残破与很旧的物件）、层次靠材质差异。

### 8.4 产品永远是主角

- 不管什么风格，产品都要清晰、完整、一眼是视觉焦点；
- 道具与氛围只衬托、不压过；
- 与手 / 道具的对比必须符合**真实尺寸（约 10cm × 4.6cm）**。

### 8.5 系列变体心法

**想象一个真人摄影师，就站在这个地点里**——他不离开空间、不打另一次光、不换时段，只换「怎么拍」。可变的轴：

- 有人 / 无人（有人只局部出镜，无脸无男性）
- 角度 / 机位（俯拍、平视、侧 45°、低角度）
- 景别（远景交代空间 / 中景；**不拍特写**）
- 产品摆放位置（仍在抬高的面上）
- 加减一个道具

**光线可微调，时段与光质锁死**：挪反光板、柔光、曝光、受光角可以变；不能把正午变成黄昏、不能把硬光改成暖调。

同一系列变体之间，**色调、时段、整体光质逐字复用基线**，其余只增量改人物 / 角度 / 景别 / 摆放 / 道具。

### 8.6 方向图怎么用

- 方向图**只用于脑内提取**场景 / 色调 / 光线 / 道具类型 / 构图 / 氛围；
- **不要把方向图垫进生成工具**，否则 AI 照抄那张图，破坏同一空间的设定；
- 方向图若是截图 / 录屏，忽略它自带的界面元素（搜索栏、时间码、播放键、字幕贴纸）。

## 9. 交付前自检

写完后逐项过，**任何一项不过就不交付**。

| 检查 | 怎么查 |
| --- | --- |
| 结构合法 | `lovart-client --check --prompts inbox/<文件>.jsonl` 必须全绿 |
| 字段干净 | 只有 `prompt` / `ratio` / `size` / `refs` |
| 公式完整 | 五个空都填了；三条固定句在 |
| 无禁用写法 | §6 六条逐条搜一遍（特写 / 占比 / 机位 / mm / f/ / 焦点 / 虚化 / 背景是 / 文字限制 / 额外负面句） |
| 场景过逻辑 | 每条能回答「女生会在这里用它吗」 |
| 产品锚定 | 每条都有 `图1的HKH胶囊精华` + `罐身比例与参考图一致、标签清晰可辨` |
| 无餐食 | 没有餐桌、餐盘、水果、甜点（饮品可以有） |
| 无男性 | 有手的只露局部、不露脸 |
| 不落地 | 全部在抬高的面上 |
| 相机合规 | §7 白名单内 |

**能证明什么**：`--check` 只证明「格式合法」，**不证明出图好看**。画面效果只能跑图看，AI 不猜、不宣称。

## 10. 设计取舍与变更记录

### 10.1 为什么是 JSONL，不是 txt

文件格式的真实职责是「AI ↔ 工具」的契约。自研 txt DSL 要人肉对齐两套语义 ⇒ 必然分叉；JSONL 两边都用标准库解析 ⇒ 结构上不可能分叉。

且旧 DSL 有个自己造出来的坑：`[nano-bn-pro]` 这种裸值会**静默丢配置**（模型退回默认），跑完几百条才发现。JSON 里不存在这种歧义。

### 10.2 不做的事

- ❌ 目录 watcher 自动执行（AI 一写就跑 = 用户没机会看）
- ❌ 提示词库 / 历史版本 / 去重
- ❌ 双向 RPC / 命令协议（`--check` / `--list-models` / `--status` 已够）

### 10.3 变更记录

| 日期 | 改动 |
| --- | --- |
| 2026-10-22 | 提示词写作规则生效（六段结构、审美放开逻辑收紧） |
| 2026-10-24 | ① 同系列改为**追加**不新建；② 新增 §4 公式与三条固定句；③ 禁特写 / 占比 / 摄影术语 / `背景是` / 文字限制句 / 额外负面句；④ 「食物」修正为**只禁餐食，饮品允许**；⑤ 新增 §7 相机准入 |

## 附录 A：参考图反推模板（另一条工作流）

> 流程第一步：拿参考图 → 用本模板反推 → 存进任务文件夹 → **之后不再回看原图**。
> 引用处：`SOP.md` §2「反推」。

如果用户给你一张图，让你参考。你可以去分析他的：

### A.1 任务描述

请分析我发给你的这张图，帮我反推出一段可以直接用于 AI 生图工具的 prompt。
你的目标不是简单描述图片，而是还原这张图的：

- 画面结构
- 主体类型
- 镜头语言
- 光影关系
- 色彩氛围
- 材质细节
- 场景信息
- 空间层次
- 情绪气质
- 媒介风格
- 负面限制

请在内部完成完整分析，但不要展示分析过程。
最终只输出可以直接复制到生图工具里的结果。

### A.2 内部分析要求

请在内部按以下步骤分析，不要把这些步骤展示给用户。

#### 1. 判断用途类型

判断这张图更接近哪种用途：

- 广告素材
- 游戏美宣 KV

#### 2. 判断媒介类型

判断这张图更接近哪种媒介：

- 摄影
- 写实 3D
- 半写实 3D
- 二次元插画
- 厚涂插画
- 扁平矢量
- 产品渲染
- UI 平面设计
- 混合媒介
- 其他

最终 Prompt 必须明确媒介边界，并排除容易混淆的错误媒介。
例如：

- 如果是写实 3D，要排除真人摄影、二次元插画、厚涂；
- 如果是摄影，要排除 3D 渲染、动漫、插画；
- 如果是产品渲染，要排除生活随拍和杂乱背景；
- 如果是扁平矢量，要排除写实摄影和复杂 3D。

#### 3. 判断主体类型

判断主要主体属于哪一类：

- 人物
- 产品
- 动物
- 食物
- 建筑室内
- 自然风景
- 城市场景
- 交通工具
- 植物花卉
- 平面海报
- 抽象图形
- 多主体混合
- 其他

后续只分析与该主体类型相关的专项，不要强行套用无关项目。
例如：

- 没有人物时，不要强行分析表情、视线、手脚；
- 没有产品时，不要强行分析包装结构或商品卖点；
- 没有文字时，不要强行分析字体；
- 没有动物时，不要强行分析毛发或眼神。

#### 4. 分析技法层

请内部分析以下内容。

**构图**

分析：

- 主体位置；
- 主体占比；
- 前景 / 中景 / 背景；
- 留白；
- 画幅比例；
- 中心构图、三分法、对称、对角线、框架式构图、散点构图；
- 斜线、横线、竖线、三角形、S 型、放射线、圆形等视觉结构；
- 哪些元素最靠近镜头，哪些元素在远处。

**镜头与视角**

分析：

- 平视 / 俯视 / 仰视 / 顶视 / 鸟瞰；
- 特写 / 半身 / 中景 / 全身 / 远景；
- 距离感；
- 广角感、自然感或压缩感；
- 近大远小透视；
- 前景遮挡、框景、透过玻璃 / 窗户 / 门缝 / 树叶观看等镜头语言。

如果不确定真实焦距，不要写具体焦距，只描述视觉效果。

**光线**

分析：

- 主光方向；
- 硬光 / 柔光 / 逆光 / 侧光 / 顶光 / 环境光；
- 轮廓光、反光、局部高光、体积光、霓虹光、窗光；
- 光晕、bloom、彩色眩光、光斑、反射高光；
- 整体冷暖；
- 光比大小；
- 光线造成的情绪。

**色调**

分析：

- 主色；
- 辅助色；
- 点缀色；
- 冷暖倾向；
- 饱和度；
- 对比度；
- 单色调、互补色、邻近色、霓虹色、高级灰、马卡龙色、复古色、胶片色、商业清透色等倾向；
- 色彩如何突出主体。

**材质**

分析：

- 主体表面质感；
- 背景表面质感；
- 皮肤、毛发、羽毛、布料、金属、玻璃、塑料、陶瓷、木材、石材、水面、液体、植物、纸张、屏幕、食物表皮等材质；
- 反光、粗糙、湿润、透明、半透明、磨砂、柔软、硬质、颗粒、织物纹理、划痕、褶皱、油光、霜感、粉末感等细节；
- 最重要的质感记忆点。

**景深与背景**

分析：

- 背景清晰、轻微虚化、中度虚化还是强虚化；
- 前景是否虚化；
- 光斑、雾气、烟雾、渐变、阴影、纹理、树影、网格、建筑轮廓、城市灯光、水面反射等；
- 主体与背景分离是否明显；
- 背景几何结构，例如横向线条、竖向线条、斜向网格、圆形光斑、大片色块、层层山脉、街道透视线；
- 背景是叙事信息还是氛围衬托。

**后期与画质**

分析：

- 颗粒、辉光、暗角、色差、锐化、柔焦、噪点、运动模糊、胶片感；
- 商业级精修、电影调色、CG 渲染后期、产品精修、皮肤修饰、镜头眩光、bloom、局部光斑；
- 画面清晰度；
- 细节密度；
- 是否有过曝、欠曝、过度磨皮、过度锐化、低清晰度等问题。

#### 5. 分析内容层

请内部分析以下内容。

**通用内容**

分析：

- 主体是谁或是什么；
- 主体的外观、形状、大小、颜色、朝向、状态；
- 辅助元素、道具、环境物件、装饰元素及其位置；
- 场景地点；
- 室内 / 室外；
- 时间感；
- 季节、天气或环境状态；
- 主体动作或状态；
- 主体、道具、背景之间的叙事或功能关系；
- 整体情绪，以及这种情绪由哪些视觉细节体现。

#### 6. 如果用户发你一个方向图，根据主体类型做专项分析

只分析与图片主体相关的专项，不要展示分析过程。

- **如果是人物图**
  分析：年龄感、性别呈现、脸部特征、发型、五官、表情、视线方向、头部角度、身体朝向、姿态、肩颈状态、手的位置、腿的位置、身体重心、哪个身体部位最靠近镜头、是否有透视强调、服装配饰、皮肤或表面细节。
- **如果是产品图**
  分析：产品类别、形状、颜色、产品朝向、产品占比、包装结构、标签/按钮/接口/边缘、表面材质、高光反射、阴影落点、水珠/粉末/液体/烟雾/冰块/花瓣等道具、是否有可读文字或logo。
- **如果是动物图**
  分析：动物种类、体型、毛色/羽毛颜色、姿态动作、眼神方向、毛发/羽毛/鳞片/皮肤/爪子质感、与环境或其他主体的关系、整体情绪。
- **如果是食物图**
  分析：食物种类、主食材、形状和颜色、摆盘方式、油光/酱汁/蒸汽/焦脆/湿润/奶油/粉末/糖霜/拉丝/滴落、餐具、桌面材质、食欲感来源。
- **如果是建筑/室内图**
  分析：空间类型、透视方向、主要线条、前中后景、材质、光线来源、空间情绪、是否需要强调整洁/无人物/无杂物。
- **如果是自然风景/城市场景图**
  分析：地点类型、时间和天气、前中后景、地平线、光线方向、空气透视、云层/水面/雾气/植被/建筑/街道透视/灯光/反射、整体情绪。
- **如果是交通工具图**
  分析：交通工具类型、角度、车身/机身材质、反射、灯光、运动感、环境、速度线/扬尘/水花、是否需要排除品牌logo或车牌。
- **如果是植物/花卉图**
  分析：植物种类、颜色、数量、状态、花瓣/叶片/露珠/花粉/纹理、光线是否透过花瓣或叶片、背景、情绪。
- **如果是平面海报/视觉设计图**
  分析：版式结构、主视觉位置、文字区域、色块关系、图形元素、留白、视觉动线、最终prompt是保留"预留文字区域"还是排除可读文字。
- **如果是抽象图形**
  分析：主要形状、分布方式、材质感、色彩关系、空间感、用途倾向。

#### 7. IP、品牌、logo、文字处理

如果图片包含 IP、角色名、品牌、logo 或可读文字：

- 分析时可以理解其作用；
- 最终 Prompt 不要依赖具体 IP、角色名或品牌名；
- 不要求生成清晰 logo 或可读文字；
- 包装、衣服印花、海报文字、角落水印等请转写为"简化图案/模糊标识/无清晰可读文字"。

#### 8. 提炼复现关键要素

在内部提炼这张图最不能丢的 3-5 个复现关键要素。
优先选择：构图、主体专项特征、光线、材质、背景几何、色彩关系、空间层次、关键情绪。
最终正向 Prompt 的前 1/3 必须优先写入这 3-5 个复现关键要素，不要把核心要素放到最后。

#### 9. 生成 Negative Prompt

Negative Prompt 需要覆盖：

- 错误媒介；
- 错误风格；
- 多余主体；
- 错误结构；
- 文字；
- logo；
- 水印；
- 杂乱背景；
- 低质画面；
- 该主体类型最容易出现的错误。

参考：

- 写实 3D：排除 real photo、anime、flat illustration、painterly style；
- 摄影：排除 3D render、anime、illustration；
- 产品商拍：排除 extra props、messy background、readable text、distorted packaging；
- 人物图：排除 extra people、distorted hands、bad anatomy、wrong expression；
- 食物图：排除 dirty table、plastic texture、inedible look；
- 建筑室内：排除 clutter、distorted furniture、wrong perspective；
- 海报设计：排除 gibberish text、random logo、low-resolution layout。

#### 10. 最终自检

输出前请自行检查正向 Prompt 是否已经包含：
主体、主体类型、构图、镜头、主体专项特征、光线、色彩、材质、背景、景深或空间层次、情绪、后期、媒介边界、负面限制、3-5 个复现关键要素。
如果有遗漏，请在输出前自行补全，不要把自检过程展示出来。

### A.3 观察纪律

能直接看到的，描述视觉结果；只能推断的，不要断言真实技术参数，而是描述视觉效果。
例如：

- 写"背景为柔和圆形光斑"，不要写"f/1.8 拍摄"；
- 写"有中长焦压缩感"，不要断言"85mm 镜头"；
- 写"呈现商业 3D 渲染质感"，不要断言具体软件或引擎；
- 写"类似黄昏暖光效果"，不要断言真实拍摄时间。

### A.4 最终输出要求

最终只输出以下两项：

1. 正向 Prompt（450-700 个中文字符，连续自然语言）
2. Negative Prompt（英文，12-20 条，逗号分隔）

不要输出分析过程、Step 列表、关键词表、自检说明、额外解释、Markdown 表格。

### A.5 最终输出格式

```
正向 Prompt：……
Negative Prompt：……
```

### A.6 方向图处理

- **方向图**：用户给风格参考图时，**只用于脑内提取**场景 / 色调 / 光线 / 道具类型 / 构图 / 氛围。
  **绝不把方向图垫进生成工具**，否则 AI 会照抄那张图，破坏同一空间的设定。
  方向图若是截图 / 录屏，忽略它自带的界面元素（搜索栏、时间码、播放键、字幕贴纸）。
