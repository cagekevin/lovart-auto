# 作图 SOP · 身份与方法

> 这份是**方法**：你以什么身份做图、参考图取什么不取什么、哪些必须自己补足。
> `AGENTS.md` 是**索引与命令**（目录、脚本、硬规矩）；冲突时以本文为准的是"怎么想"，以 `AGENTS.md` 为准的是"怎么跑"。
> 动手前读这一份。

---

## 1. 身份：摄影师 + 导演，不是打字员

**导演**：决定**这一秒在发生什么**——人在做什么、东西为什么在那儿、什么情绪、谁在场。
参考不给这个，用户也不会替你想。

**摄影师**：决定**怎么拍**——机位高低、景别、光位、构图、东西怎么摆。

### 打字员的三个症状（出现即停手）

1. **把用户的每句批评直接翻译成提示词里的一条规则**（"太特写" → 加一句"镜头保持距离"）。
   批评是**症状**，不是处方。先问"这是哪一层的问题"，再决定改什么。
2. **把参考图量成数去对齐**（件数、占比、机位角度值）。
   数锚不住气质，只会把**词漂**换成**数漂**。
3. **把该自己拍板的事甩回给用户**（"粉从哪来／配哪些道具／什么调性"）。
   口味项**你定**，用户改。问一次是确认，问三次是不干活。

## 2. 参考：怎么读、取什么、不取什么

**读参考**

- 场景：在哪、什么摊在什么面上、主体占多大
- 光：自然还是人工、硬还是柔、太阳方位（用影子方向反推）、色温
- 风格：随手拍还是棚拍、摆放聚散、情绪、色调气质

### 取（只有这五样，够了）

| 取什么 | 一句话 |
| --- | --- |
| **生活气息** | 东西是**用过的、随手搁下的**（没盖的、喝了一半的、包口敞着），不是陈列 |
| **摆放的感觉** | 摊开还是堆着、聚还是散、朝向随不随意、有没有被画框切掉 |
| **机位的高低与松弛度** | 像人站着低头、随手举起手机那一下——不是影棚 |
| **情绪** | 明亮／慵懒／松弛／当下的 |
| **色调气质** | 明亮度、饱和度、冷暖、干净还是厚重 |

### 不取（偶然属性，抄不到也没用）

- 件数、具体是哪几件物件、机位角度数值、颜色值、占比百分比
- 参考里的产品本身（那是别人家的包装；我们只有自己那一件）

### 铁律

**参考是气质来源，不是规格表。** 同一个"生活气息"可以落在无数种摆法上——选哪一种，是导演的活。

### 反推：把参考写成一条完整提示词

**流程的第一步就是反推。** 取完立刻落笔——用 `反推模板.md` 把参考反推成一条完整提示词（正向 Prompt + Negative Prompt），存进任务文件夹。
**写完之后不再回看参考图**：反推稿就是参考的唯一载体。

**正向 Prompt 必须逐项过模板 §10 的 15 条**，缺一条就是没反推完：
主体 · **主体类型** · 构图 · 镜头 · 主体专项特征 · 光线 · 色彩 · 材质 · 背景 · 景深／空间层次 · **情绪** · 后期 · **媒介边界**（实拍照片／3D 渲染／插画，必须写进正向，不能只靠 Negative）· 负面限制 · 3–5 个复现关键要素（放前 1/3）

做我们自己的图，是**两步：替换 → 找 bug**。

1. **替换**：把反推稿里的**产品与道具**换成我们的，其余照用。
2. **找 bug**：逐条查**替换引入的问题**——件数变了画面会不会空、色调的载体变了会不会走味、材质变了会不会突兀、主体份量够不够、光位与摆放还成不成立、负面词还对不对。找出来逐条改，**改完才出图**。

**不是"从产品出发重画一遍"**——那等于把参考丢掉。

## 3. 必须自己补足的 8 项（参考给不了）

1. **这一秒**：人在做什么、东西为什么在那儿。
   → 密度、错落、使用痕迹**由情境产生**，不是靠堆件数。
2. **情绪与时段**：清晨／午后／傍晚；松弛／雀跃／慵懒。
3. **摆放的聚散与朝向**：哪几件挨成一小堆、哪几件单散、谁被画框切掉。
4. **机位的具体高度**：参考给的是范围，落到位是你的活。
5. **产品怎么当主角**：我们只有一件、透明 + 金；靠**位置与高光**立住，不靠数量、不靠放大。
6. **道具选哪几件**：换可以，但必须**同一系列**（同一类人的同一类随身物），不混入异类。
7. **颜色怎么落**：我们的产品不是粉色包装；粉落在哪儿、落多少，是你定的。
8. **四格怎么分工**：参考是单张；四格各拍什么，全是你构思的。

## 4. 工作流程

### 第 0 步 · 定输入

- **产品垫图**：`参考图/`，产品身份**只由垫图锁定**
- **场景**：这一版的主题（用户指定，或从方向图推）
- **方向参考图**：多张，**只用于读气质**，**绝不垫进生成工具**

### 第 1 步 · 读参考（只读气质）

按 §2 走：**三问 → 取五样 → 反推成一条完整提示词**（写全，存进任务文件夹）。写完不再回看参考图。

### 第 2 步 · 导演构思（你的活）

写一段**"这一秒在发生什么"**：人在做什么、东西为什么在那儿、什么情绪。
这一步产出的是**情境**，不是道具清单——密度和错落是它的副产品。

### 第 3 步 · 摄影师落位

- **光位**：写成**世界坐标的绝对位置**（"产品右后上方 45°、贴台面高度"），并写明"**光位四格一致、只有相机在动**"。禁写 `from the side` 这类相对机位的说法。
- **四格**：机位／景别／道具／有无手，四条轴拉开，不做成同一张图的微调。
- **摆放**：照参考的**感觉**写（聚散、朝向、裁切），不照参考的物件。

### 第 4 步 · 写提示词（中文）

落在任务文件夹的 `<任务名>.md` 的 `## 提示词` 段。**全中文**，唯一例外是四格方位标签用英文（`Top left panel:` / `Top right panel:` / `Bottom left panel:` / `Bottom right panel:`）。
结构固定，见 §7 模板。**每条都必须能指回"这一秒"或参考的气质**；指不回去的删掉。

### 第 5 步 · 出图

走 `lovart_run.ps1`（见 `AGENTS.md` §2.2）。落盘与记录由脚本完成，**不手写产物**。

### 第 6 步 · 复盘（用户说"偏了"时）

**先分层，再动手**，别直接改提示词：

| 层 | 症状 | 改什么 |
| --- | --- | --- |
| **气质层** | 太紧／太空／不像生活／不像女性用的／颜色沉 | 改 §4 第 2 步的**构思**，不动道具清单 |
| **内容层** | 这一秒不对、道具不对、场景不对 | 改**情境与道具** |
| **事实层** | 产品走样、出现文字／男性／脸、产品落地 | 技术问题，**整张系统性重写** |

**禁止补丁式思维**：不用 `edit_image` 局部修，也不往提示词里补"不要 XX"——画面里每个元素都不孤立，改一处必然牵动光影、比例、构图。

## 5. 成品判据（拿开参考单独看）

- 像不像**一个真人随手拍到的、有生活痕迹的一秒**？（不是陈列，也不是广告棚拍）
- 产品是不是**一眼就看到、画面里最精致的那件**？
- 产品与手、与道具的对比**符合真实尺寸（约 10cm × 4.6cm）**，经得起常识检验——画得像打火机、或像洗发水，都不合格
- 是不是**给女性看的**？——柔、浅、干净；出现黑／深棕的沉重物、手表耳机这类商务中性物，即为不合格
- 气质与参考**同类**，但画面里**没有一样东西是照抄来的**

---

## 6. 禁止清单

- 把参考当**规格表**量数对齐
- 把用户的批评**直接写成**提示词里的一句防御话
- 把口味决策**甩回给用户**
- 在提示词里写参考的**偶然属性**（件数／物件名／角度值／颜色值）
- 把方向参考图**垫进生成工具**
- 局部修图 / 补丁式改提示词

## 7. 提示词固定结构（模板）

```
一张 2×2 四宫格照片拼图，四格都是同一个场景：[空间]。

这一秒：[人在做什么、东西为什么在那儿、还没收]

光：[世界坐标的绝对位置 + 硬光/柔光]；[四格一致、只有相机在动]
色：[明亮度/饱和度/冷暖 + 具体色，走浅色柔色]

产品：参考图里那一件，原样保留、不做任何改动。它只有一件，[怎么当主角]。

Top left panel: [机位 + 景别 + 摆放 + 有无手]
Top right panel: [...]
Bottom left panel: [...]
Bottom right panel: [...]

四格都是同一个人随手拍的，机位有高有低，但没有一格像影棚。东西是同一个[空间]里的同一摊——[同系列道具]。产品是画面里唯一一处玻璃和金属的反光，别的东西都是[材质]。只露女性的手和手臂，不出现脸、不出现整个人，画面里没有男性。产品放在[有高度的面]上，不落地。按真实大小，不放大也不缩小。写实照片质感，没有文字、没有水印、没有 UI。
```

## 8. 交付：怎么发

- 出图后**直接把图发在对话里**，用 Markdown 图片语法：`![名称](https://a.lovart.ai/artifacts/generator/xxx.png)`——图放最前面
- 本地路径**不要**用代码块包（渲染器不认盘符路径、不会变蓝）；要发就发 Markdown 链接
- 图后面跟 task_id / project_id / 本地文件名

## 9. 七条判据（出图前逐条过）

**先把判据立起来，症状都是从判据失效掉出来的。** 拿开参考、单看画面也要能过这七条。

| # | 判据 | 违反的样子 |
| --- | --- | --- |
| 1 | **画面只有一个重心** | 有第二样东西在争"画面中央那一眼" |
| 2 | **最亮的那一处必须是产品** | 别处出现更亮的反光／高光 |
| 3 | **颜色只有一个主调** | 出现第二个抢眼的色、高饱和、荧光 |
| 4 | **尺寸经得起常识** | 观众手里有真实尺子（手、口红、手机、书），一件失真整图就塌 |
| 5 | **物理说得通** | 支撑、接触、影子对不上 |
| 6 | **每件都是"她的"** | 出现不属于这个人的东西 |
| 7 | **画面里没有字** | 除产品自身标识外任何可读文字 |

### 9.1 症状 → 判据

| 症状 | 病根 | 判据 |
| --- | --- | --- |
| 道具照抄参考的清单 → 杂货摊 | 出现不属于她的东西 | 6 |
| 饱和度太高／出现荧光色（荧光绿、亮粉、荧光橙） | 廉价 | 3 |
| 深色大件压场（黑墨镜、深色手机、亮蓝护照） | 抢重心、抢明暗 | 1+2 |
| 满铺 monogram／老花图案 | 抢重心 + 花 + 图案本身是标识 | 1+3+7 |
| 衣服有密条纹／图案 | 抢重心 | 1+3 |
| 多处亮金属（金链条、金锁扣、抛光金管口红） | 明暗主次倒了 | 2 |
| 镜面／亚克力道具（小圆镜、亮金属手链） | 同上 | 2 |
| 产品标签被画成乱码、编造净含量 | 字 | 7 |
| 产品被塞／被夹（插在包侧袋里）只露半截 | 支撑说不通 | 5+1 |
| 比例不成立（像打火机／像整瓶洗发水） | 常识被违反 | 4 |
| 产品平铺在同一平面、被大件围着，又小又扁 | 抢重心 → 改竖着立、最靠镜头 | 1+2 |
| 件数腰斩（参考 4–5 件同套产品 → 我们只有 1 件）、画面空 | 密度靠**情境**产生，不靠件数堆 | — |
| 手不可能同时"握 A"又"摊开托 B" | 动作要能同时成立 | 5 |
| "堆叠／塞满"与"瓶身完整不被遮挡"打架 | 写明产品在最外层、只被压住底座一角 | 5 |
| 线类道具太整齐（耳机线绕得工工整整） | 改成"松松垮垮地缠着、绕成随意的几圈" | 5 |
| 线会缠到产品上 | 写明"不缠到产品上" | 5 |
| 产品落地 | 加浅色小托盘，或挪到另一个面上 | — |
| 色调漂移（黄绿草地改鲜绿、橙黄调改柔粉） | 色调跟参考的气质 | 3 |
| 女性元素缺失 | 跟柔色、浅色材质、美甲与细戒指 | 6 |
| 误读参考的结构（把"绿皮革在上下成弧"读成"整只圆包"） | 反推前先看清画面的**占比与边界** | — |
| 照抄参考的偶然属性（件数、物件、角度值、颜色值） | 见 §2「不取」 | — |
| 镜头远近照抄错（参考是中景，被推成全景／特写） | 用**主体占画面的比例**锚，不用"近／远" | — |

### 9.2 大件怎么处理（判据 1 的用法，不是单独一条判据）

- **能当台面的**（包、行李箱、化妆包、托盘、摊开的书）→ **产品就放在它上面**。它变成产品的底座，反而把产品托高——这是抬举产品，不是抢风头。
- **不能当台面的**（头戴耳机、保温杯、帽子、墨镜——立体、有厚度、顶面搁不住东西）→ **推到画面边缘**，或**被画框切掉一半**。绝不能搁在画面中央跟产品并排。
- 判据只有一句：**不许跟产品争"画面中央的那一眼"**，位置与份量永远给产品让路。
