## 2. 调用方式：MCP 优先，脚本兜底

### 2.1 首选：直接调 MCP 工具

服务端：`https://lgw.lovart.ai/v1/openapi/mcp/widgets`（配在 `.mcp.json`）。

会话里能用 `generate_image` / `edit_image` / `upload_asset` 等工具时，**直接用**，不要去摸脚本。

服务端当前提供 18 个工具，常用参数（`*` = 必填）：

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| `generate_image` | `prompt*`, `model`, `ref_images`, `aspect_ratio`, `n`, `project_id`, `params` | 出图主入口 |
| `edit_image` | `images*`, `prompt*`, `model`, `project_id`, `params` | 改图 / 定向修复 |
| `upload_asset` | `filename*`, `url`, `data_base64`, `project_id` | 本地图换 URL，喂给 `ref_images` |
| `generate_video` | `prompt`, `model`, `first_frame`, `last_frame`, `ref_images`, `ref_video`, `aspect_ratio`, `duration`, `project_id`, `params` | 出视频 |
| `get_credits` | — | 查额度，**不消耗** |
| `get_task_status` / `get_task` | `task_id`, `task_ids`, `project_id`, `include_images` | 查生成进度 |
| `list_models` | `kind`（`image` / `video`） | 列模型，**不消耗** |
| `describe_model` | `model*` | 查模型参数，**不消耗** |
| `list_projects` / `create_project` / `rename_project` | — | 项目管理 |
| 其他 | `upscale` `vectorize` `separate_layers` `remove_video_background` `cancel_task` `jev` | 按需 |

常用图像模型名：

- `openai/gpt-image-2`（服务端默认）
- `vertex/nano-banana-2`、`vertex/anon-bob`（Nano Banana Pro）、`vertex/nano-banana`
- `openai/gpt-image-2-5-sunburst`、`openai/gpt-image-2-5-flare`、`openai/gpt-image-1-5`
- `seedream/seedream-5-0-pro`、`seedream/seedream-5-0`、`seedream/seedream-4-5`
- `fal/flux-2-pro`、`fal/flux-2-max`、`qwenimage/qwen-image-3-0-pro`、`ideogram/ideogram-v4`

> 用户没指定模型时**不要臆测**，走服务端默认。

### 2.2 兜底：MCP 没挂载时走脚本

**出图走 `lovart_run.ps1`**（提交 → 轮询 → 落盘 → 刷新调用记录，一条命令跑完）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "G:\01画布项目\lovart-auto\ai联动出图\script\lovart_run.ps1" `
  -PromptMd "G:\01画布项目\lovart-auto\ai联动出图\生成图\参考1_草地帆布包\参考1_草地帆布包.md" `
  -ArgsFile "G:\01画布项目\lovart-auto\ai联动出图\script\_args_model.json" `
  -RefImage "G:\01画布项目\lovart-auto\ai联动出图\参考图\HKH产品.jpg"
```

`-PromptMd` 决定输出目录与文件名（文件夹 = 它的父目录，文件名 = 它的基名）；提示词从它的 `## 提示词` 代码块读，跑完只刷新 `## 本次调用` 段。`-ArgsFile` 只放 `model` / `aspect_ratio` / `ref_images` / `params`，**不放 `prompt`**。按服务端返回的 `poll_after_seconds` 轮询 `get_task_status`，到 `completed` 再取 artifacts 落盘；失败／超时抛错并带任务号。

**单工具调用**（查询类，或要手工控节奏）走 `lovart_call.ps1`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "G:\01画布项目\lovart-auto\ai联动出图\script\lovart_call.ps1" -Tool get_credits
```

`-Tool` 工具名，`-Args` 工具参数 JSON 字符串（默认 `{}`），`-ArgsFile` 从文件读。返回体是原始 JSON。

### 2.3 脚本清单（只在必要时碰）

| 脚本 | 什么时候用 |
| --- | --- |
| `lovart_run.ps1` | ★ 出图主通道：提交 + 轮询 + 落盘 + 记录一条命令跑完 |
| `lovart_list_tools.ps1` | 诊断：确认令牌是否有效、服务端有哪些工具。**不消耗 credits** |
| `lovart_token_refresh.ps1` | 令牌过期（工具变空 / 报 401）时日常续期，用 refresh_token 换新 |
| `lovart_reauth.ps1` | refresh_token 也失效时，走浏览器 OAuth 重新授权。**需要人工点授权** |
| `lovart_apply_config.ps1` | 把令牌同步进 `.mcp.json`，由上面两个自动调用，**一般不用手动跑** |
| `lovart_call.ps1` | 通用调用器，MCP 不可用时的兜底通道 |
| `lovart_migrate_scope.ps1` | **已作废**（2026-09-24 一次性执行完，仅留档） |

令牌有效期 30 天，存于 `~/.lovart/mcp_oauth.json`。
如果会话里 lovart 工具不可见：先确认 `.mcp.json` 存在 → 重载工作区 / 重启 IDE；仍不行就跑 `lovart_token_refresh.ps1`，最后才用 `lovart_call.ps1`。

## 3. 作图标准流程

### 第 0 步 · 搞清输入

- **产品垫图**：从 `参考图/` 取。产品身份只由垫图锁定。
- **方向图**：用户给风格参考图时，**只用于脑内提取**场景 / 色调 / 光线 / 道具类型 / 构图 / 氛围。
  **绝不把方向图垫进生成工具**，否则 AI 会照抄那张图，破坏同一空间的设定。
  方向图若是截图 / 录屏，忽略它自带的界面元素（搜索栏、时间码、播放键、字幕贴纸）。
- **有方向图时不要拿候选场景反问用户**，方向图就是需求表达，直接推导方案。
- 既没有方向图、也没有场景信息时，才用 `ask_human` 让用户选场景（咖啡桌 / 汽车中控台 / 包内 / 晨起梳妆台 / 野餐）。
- 默认产出就是**一张** 2×2 四宫格，**不要问"要几张"**。

### 机制 · 一个任务一个文件夹（每次必做）

出图落成 `生成图/<任务名>/`，文件夹里就是这次任务的全部：

| 文件 | 谁写 | 说明 |
| --- | --- | --- |
| `<任务名>.md` | 提示词人写，调用记录脚本刷新 | ★ **唯一真源**：`## 提示词` 段（中文，人改这里）+ `## 本次调用` 段（模型／比例／垫图／task_id／出图文件名，脚本每次覆盖） |
| `垫图.jpg` | 脚本拷入 | 本次发送的产品垫图副本，锁定身份锚点 |
| `<任务名>.png` | 脚本下载 | 出图 |
| `<任务名>_<版本>.png` / `.md` | 脚本 | 历史版本，作为下一版的增量基线 |

落盘与记录一律由 `lovart_run.ps1` 完成，**不手写产物**。

改需求时**以上一版为基线做增量**，不要重写——重写会让不该变的东西（光位、色调）跟着漂移。

**光位尤其注意**：必须写成**世界坐标的绝对位置**（"产品左后方 45°、贴台面高度"），并写明"光位四格一致、只有相机在动"。写成 `from the side` 这类**相对机位**的说法，一改机位光就跟着变。

**不要主动看生成的图片**——除非用户明确让你看。出图后只做两件事：落盘、报文件名。

**接受模型的随机性**：效果不满意就直接重跑，不要为单张图做特判或加一堆补丁。

### 第 1 步 · 读技能，出中文方向

读 `skills/生活化的4宫格场景图.md`，按它的规则产出。**全流程只有中文**：给用户看的方向是中文，发出去的提示词正文也是中文——提示词落在任务文件夹的 `<任务名>.md` 里，用户一眼能看、能直接改。**唯一例外是四格方位标签**：`Top left panel:` / `Top right panel:` / `Bottom left panel:` / `Bottom right panel:` 用英文（方位是模型最吃英文的一处），其余一律中文。格式：

```
🎬 场景主题：[同一空间名称]
整体基调：[一句话讲清调性]

中文分镜构思（四格同一空间，内容各自独立）：
· 面板1（视角A）：[视角 + 景别 + 有手/纯静物 + 手部动作 + 道具]
· 面板2（视角B）：[...]
· 面板3（视角C）：[...]
· 面板4（视角D）：[...]

光线色调：[怎么打光、以什么颜色为主]
画面里有什么、没有什么：[道具；有没有人、出镜部位；避开什么]
```

### 第 2 步 · 等用户点头（硬门禁）

**用户认可中文方向之前，绝对不调生图工具。** 用户提修改就改中文方向再给一次，直到认可为止。**认可的对象是中文方向（或任务文件夹里的中文提示词），不是调用参数。**

### 第 3 步 · 生图

- 一次生成**一张** 2×2 四宫格（四格在同一张图内，**不是分四次生成四张**）。
- 产品图必须进 `ref_images`（本地图片先 `upload_asset` 换 URL）；只在 prompt 里文字描述 **不算** 锚点。
- 默认竖版 3:4。
- 用户有明确模型偏好才设 `model`，没指定不臆测。
- 生成会消耗 credits；动手前可用 `get_credits` 看一眼。
- 落盘与记录走 §2.2 的 `lovart_run.ps1`：不手搓调用、不手写产物。

### 第 4 步 · 交付与自检

- 结果落到 `生成图/<任务名>/`，由 `lovart_run.ps1` 落盘，不要手工挪。
- **禁止补丁式思维。** 出现问题就要**系统性地重新写**：不要用 `edit_image` 局部修，也不要往提示词里补一句"不要 XX"。因为**画面里每个元素都不是孤立的**，改一处必然牵动光影、比例、构图——打补丁只会越补越烂。
- 自检不通过同理：**不是"回去改那一处"，是整张系统性重写。**

### 变体的定义（用户说"再给我几张 / 多来点变体 / 换换拍" 时）

当用户在**已认可的一套方向**（例：「泳池边躺椅 · 法式慵懒 · 正午硬光」）基础上要"变体 / 更多张 / 换换拍"时，**变体 = 同一地点、同一风格、同一光位与色调**。

#### 心法：想象一个真人摄影师，就站在**这个地点**里

变体就是这位摄影师在**原地**能做的所有动作——他不离开这个空间、不打另一次光、不换时段，只是换"怎么拍"。可变的轴：

- **有人 / 无人**：四格里有的格有局部人物（手 / 手臂 / 肩 / 腿，无脸无全身无男性），有的格纯静物（只有产品 + 道具）。同一张图内可混搭。
- **摄影角度 / 机位**：俯拍 flatlay、第一人称 POV、平视特写、45° 侧、低角度、从背后、贴水面仰拍……随便换。
- **景别**：远景交代空间 / 中景 / 近景特写。
- **产品摆放位置**：桌 / 躺椅椅面 / 托盘 / 椅边，仍在「抬高的面」上，绝不上地。
- **加 / 换一个道具**（仍遵守道具最多一个限定词）。
- **四格构图**：非对称、错位、前景虚化遮挡等，重新排布。

**光线可以微调，但时段与整体光质锁死**：摄影师在原地能做的打光调整都允许——挪反光板 / 加柔光罩、微调受光角度、调曝光、让光斑位置轻微移动等；但**不能把中午变成晚上、不能把正午硬光改成黄昏暖光**——时段（正午 / 黄昏 / 夜）和整体光质（硬光 / 柔光 / 暖调）属于"另一套方向"，不是变体。
（反例：泳池边躺椅的「黄昏金光」版把正午硬光改成了黄昏暖光，改了时段与整体光质，不算该系列变体，是错误示范。）

同一系列变体之间，**色调、时段、整体光质必须逐字复用**基线 MD；摄影师原地的打光微调（反光板 / 柔光 / 受光角 / 曝光）允许。其余只增量改"人物有无 / 机位 / 景别 / 摆放 / 道具 / 构图"，避免不该漂移的东西跟着漂移。

## 4. 硬规矩速查

从技能里提炼，违反直接重做。分组与技能里的《绝对禁令》一致：

**一、我的偏好（口味）**

1. 四格必须**同一空间**（同一辆车 / 同一张桌 / 同一个房间），不许跨到第二个地点；但**四格内容允许完全不同**——机位、景别、道具组合随便换。
2. 四格要**真正拉开差异**，不许做成"同一张图的微调"。**不强制每格有人**：有的格有手，有的格可以纯净物（只有产品和道具）。
3. **方向参考图不垫进生成工具**（用户明确要求保留的硬规矩）。
4. 道具**最多一个限定词**，不堆颜色 / 款式 / 材质。
5. **无任何 UI 元素与文字**（时间、搜索栏、播放键、水印、字幕贴纸）；除产品自身品牌标识外不加文字。
6. **不出现整个人和脸，也不出现男性**——产品面向女性用户，画面里有男性即为不合格。人物非每格必需；一旦出现，只允许局部出镜（手 / 手臂 / 肩 / 腿）。
7. **产品不放地上**：只能放椅子 / 沙发 / 桌子 / 台面 / 托盘 / 腿上；地板、地毯、草地、马路一律不允许。

**二、技术事实**

8. 四宫格是**一个图片资产**，必须一张图内含四格，不分四次生成。
9. 提示词里**不复述产品外观**（瓶型 / 瓶盖 / 铭牌 / 文字），只用一句「图中的产品原样保留、不做任何改动」带过；身份只靠垫图。
10. 不编造产品没有的功效 / 品牌 / 外观 / 价格。

**三、流程铁律**

11. **用户认可中文拍摄方向之前，绝不调生图工具。** 提示词本身也是中文、就放在任务文件夹里，用户随时能看能改；**不需要单独确认提示词**，要确认的是拍摄方向。
12. 信息足够时不反问；默认出一张四宫格，用户另说则照办。既没方向图又没场景信息时，才用 `ask_human` 让用户选。

**四、美学口径**

13. 主目标：**慵懒的精致抓拍感**——姿态松弛、构图随意，但画面完成度不降。
14. 色调**以方向图为准**，有方向图时不要套技能的默认奶油色。
15. **产品永远是主角**：不管什么风格，产品都要清晰、完整、一眼是视觉焦点，道具与氛围只衬托、不压过。**比例**上，与手 / 道具的对比必须符合**真实尺寸（约 10cm × 4.6cm）**。
16. 女性元素：方向图有柔美感（粉调 / 毛绒 / 美甲 / 蕾丝）就直接跟上；没有则不主动加。

## 5. 常见故障

| 现象 | 处理 |
| --- | --- |
| 会话里没有 lovart 工具 | `.mcp.json` 是否在 → 重载工作区 / 重启 IDE → `lovart_list_tools.ps1` 验证 |
| MCP 报 `connect failed` / `Connect Timeout ...:443` | **已于 2026-09-24 确诊，别再重复排查**：① DNS 被污染，`lgw.lovart.ai` 解析成 `108.160.165.9` / `face:b00c::` 段；② 真实 IP 是 Cloudflare `104.18.6.126`，但直连它 **TCP 通、TLS 被 RST** → **SNI 阻断**，所以**改 hosts 无效**；③ 代理环境变量（`HTTPS_PROXY` + `NODE_USE_ENV_PROXY=1`，已写入用户变量且确认进了 IDE 进程）**无效**，IDE 的 fetch 不读它们，别再试；④ **唯一有效解法：代理客户端开 TUN 模式**（网卡层接管，DNS 一并走代理），开完 `Reload Window` 即可。ps1 通道一般不受影响（.NET 吃 Windows 系统代理），但它也可能失败——见下一行 |
| ps1 报 `连接失败 (HTTP )`（HTTP 码为空 ⇒ 网络层错，**不是 401**，别去刷令牌） | .NET 这次没取到系统代理。先 `Test-NetConnection 127.0.0.1 -Port 7897` 确认本地代理在听，再显式挂代理重跑：`[System.Net.WebRequest]::DefaultWebProxy = New-Object System.Net.WebProxy('http://127.0.0.1:7897')`。`lovart_run.ps1` 已内置自动解析（env `HTTPS_PROXY` → WinINET），取不到就传 `-Proxy` |
| HTTP 401 / 工具变空 | `lovart_token_refresh.ps1` |
| 刷新也失败 | `lovart_reauth.ps1`（需人工在浏览器授权） |
| ps1 报 `invalid_request` | Windows PowerShell 默认发 `Expect: 100-continue`，脚本里已关掉；自己写调用时要一并关闭 |
| 想查还剩多少额度 | `get_credits`（不消耗） |
