# 参考8_一手抓满

- 基线 = `参考反推\参考图8_一手抓满.md`（反推稿）；**替换产品与道具 → 找 bug → 改完才出图**
- 场景：一整面浅灰水泥墙（大面积留白）；一只手从画面**左侧水平**伸入，手腕在画面中下部、**掌心朝上、四指朝上张开**；东西**竖着立／插在手掌与手指上、前后错开**——**不是摊平压在掌心里**
- 道具（7 件，**全是女性用品**，全部**视觉降高**）：一只**小号矮身奶油色陶瓷杯**（无盖、无提手）、一支**橙色**护手霜软管（斜插）、一支没盖的**橙色**唇釉（斜插）、一只哑光浅粉粉饼盒（平放在掌心）、一只缎面粉色发夹（挂在手指上）、一只薄荷绿毛绒发圈（挂在手指上垂下）、一副白色有线耳机（线松散地搭着）
- 颜色：**橙 + 奶油黄 + 白 + 灰墙**为主，柔粉与薄荷绿作点缀（跟参考的橙黄暖调）
- 内容身份：**「一手抓满给你看」**
- 产品只有一件，**竖着立在画面中央偏前、最靠镜头**；**按真实尺寸（约 10cm 高 × 4.6cm 宽）**，与手、与掌上那些东西的对比要经得起常识——画得像打火机或像洗发水都不合格

**替换引入的 bug（已逐条修）**

1. 参考里**保温杯是最大的东西**、占视觉重心 → **不撤杯子，换成一只小号矮身陶瓷杯**。参考那个是 20cm 以上、带盖带吸管的保温杯，等于给画面立了个参照物，我们 10cm 的瓶放旁边怎么排都显小；换成矮杯既保留"手里有杯子"，又不占高度。其余道具一律**视觉降高**（斜插／平放／垂下），并让产品成为画面里**唯一竖着立、最靠镜头**的一件——但尺寸仍按真实比例，不靠"画大"取胜
2. 参考的**银色金属表带手表是亮金属**，会抢产品瓶盖的高光 → **去掉手表**（手腕不戴任何东西）
3. 参考的**黑框眼镜与深色手机**是两件深色大件、且不算女性用品 → **去掉这两件**，道具全换成女性用品
4. 我们的产品是矮胖圆瓶，**不能像软管那样插在杯旁** → 改成**握在手里**，瓶身完整、金盖朝上
5. 耳机线**不能整齐**——整整齐齐绕在手机上像摆拍 → 写成"**松松垮垮地缠着、绕成随意的几圈、有一截垂下来**"，并写明**不缠到产品上**
6. **手不可能同时"握产品"又"摊开托一堆东西"**（物理矛盾）→ 产品改成**和别的东西一起放在同一只摊开的掌心里**，不单独握着
7. **一手抓满必然互相叠压**，与"瓶身完整不被遮挡"打架 → 写明产品**放在最上面一层**、只被一件东西压住底座的一角、瓶身其余部分完全露出
8. 色调从参考的**橙黄**偏成了"柔粉为主" → 把橙黄找回来：奶油黄随行杯 + 橙色护手霜 + 橙色唇釉，柔粉只作点缀
9. **拿法错了**——参考是"掌心朝上、四指朝上张开，东西**竖着立／插在手掌与手指上、前后错开**"；我写成"放在掌心里、最上面一层"，等于**把东西摊平压在巴掌大的掌心里** → **每件都被缩小**。改成竖着立、前后错开、互不遮挡（保温杯后来换成小号矮身陶瓷杯，见第 1 条）
